The Balmer Absorption Line Ratio fittinG (BALROG) code performs a fit of the ratio of the Balmer absorption lines, measured from a galaxy spectrum, to infer the stellar metallicity.

Note: BALROG is currently designed to work only with the sMILES stellar population library. Before running the code, it is necessary to download the .npz file containing the models from zenodo using the link provided in the "ssp_models/download_smiles.txt" file and move it to the same folder.
